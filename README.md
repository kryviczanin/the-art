# The Art

This is my first website, built while I am learning HTML, CSS, and JavaScript. It features a centered artwork, custom typography, a favicon, responsive design, and a soft animated glow effect.

The artwork captures two snow-covered garages standing quietly in a winter landscape. Often described by absolutely nobody as a masterpiece of modern art, the painting explores themes of silence, nostalgia, and the possibility that one of these garages contains something far more valuable than the artwork itself. As both the website and its creator are still learning, occasional imperfections should be considered part of the artistic experience.

## Features

- Responsive layout without page scrolling
- Centered artwork
- Header and footer text
- Google Font: Great Vibes
- Favicon support
- JavaScript-powered glow layer animation
- Automatically updated footer year

## Files

- `index.html` contains the page markup.
- `assets/css/style.css` contains the layout, responsive rules, and glow layer styling.
- `assets/js/main.js` updates the footer year and animates the glow layer.
- `assets/content/art.png` is the main image.
- `assets/content/favicon.ico` is the browser tab icon.
- `LICENSE` contains the project license.
