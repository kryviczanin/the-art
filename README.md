# The Art

This is my first website, built while I am learning HTML and CSS. It features a centered artwork, custom typography, a favicon, responsive design, and a subtle glow animation. The artwork captures two snow-covered garages standing quietly in a winter landscape. Often described by absolutely nobody as a masterpiece of modern art, the painting explores themes of silence, nostalgia, and the possibility that one of these garages contains something far more valuable than the artwork itself. As both the website and its creator are still learning, occasional imperfections should be considered part of the artistic experience.

## How To Open

Open `index.html` directly in a browser.

```bash
open index.html
```

## Features

- Responsive layout without page scrolling
- Centered artwork
- Header and footer text
- Google Font: Great Vibes
- Favicon support
- Animated glow effect on the image

## Files

- `index.html` contains the page markup.
- `assets/css/style.css` contains the layout, responsive rules, and image glow animation.
- `assets/content/art.png` is the main image.
- `assets/content/favicon.ico` is the browser tab icon.
